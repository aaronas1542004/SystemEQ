SystemEQ — Live System-Wide Audio Equalizer for Windows 10 / 11
===============================================================

Controls Sub-Bass (45 Hz Low-Shelf), Bass (110 Hz), Vocal (2.5 kHz),
and a live Low-Pass Filter (120 Hz - 20 kHz, 12 dB or 24 dB/oct) across
Spotify, browsers, games, and ALL Windows audio apps and output devices.

Quick Setup (One-Time):
1. Extract this folder anywhere permanent (e.g., Documents\SystemEQ).
2. Double-click "Launch_SystemEQ.vbs" to open the app.
3. If the top badge says "Equalizer APO Not Installed":
   - Click "Download Equalizer APO" (free open-source Windows audio engine).
   - Run the installer, check all your output devices (laptop speakers,
     Bluetooth earbuds, wired headphones, HDMI) in the Configurator popup,
     and reboot once.
4. Re-open SystemEQ — it auto-links to Equalizer APO and shows
   "APO Linked • Live DSP" in green.
5. Click "Add Start Menu App" inside the app to pin SystemEQ to your
   Windows Start Menu and Desktop so you can launch it like any installed app.

Adding New Earbuds / Devices Later:
- Connect the device, click "Select Output Devices" inside SystemEQ,
  check the new device, and restart audio (or reboot).
